reel n’est pas sur l’App Store. On l’installe avec SideStore, une app gratuite qui installe des apps avec votre propre identifiant Apple.

SideStore Recommandé

  1. Installez SideStoreSuivez son guide. Il faut un ordinateur une seule fois, une dizaine de minutes.Guide de SideStore
  2. Ajoutez reelOuvrez cette page sur l’iPhone et touchez le bouton.Ajouter reel à SideStore
  3. InstallezDans SideStore, ouvrez reel et touchez Installer.

SideStore renouvelle reel tout seul tous les 7 jours et apporte ses mises à jour. iOS 15 ou plus récent.

Vous utilisez déjà AltStore Classic ?

Laissez AltServer ouvert sur un ordinateur du même réseau Wi-Fi, sinon reel ne s’ouvre plus au bout de 7 jours.

reel n’est pas dans la boutique d’apps de Samsung. Configurez TV-⁠Store une fois depuis un ordinateur, puis installez et mettez à jour reel avec la télécommande.

TV-⁠Store Recommandé

  1. Activez le mode développeurSur le téléviseur, ouvrez Apps et tapez 1 2 3 4 5 sur la télécommande. Activez le mode développeur et saisissez l’adresse IP de votre ordinateur.
  2. Configurez TV-⁠StoreDans Apps2Samsung sur l’ordinateur, installez TV-⁠Store sur le téléviseur et appuyez sur Arm TV-⁠Store dans la Toolbox du téléviseur. Remplacez ensuite l’IP du mode développeur par 127.0.0.1.Guide de TV-⁠Store
  3. Installez reelOuvrez TV-⁠Store sur le téléviseur, trouvez reel et appuyez sur OK.

Ensuite, plus besoin d’ordinateur : les mises à jour de reel apparaissent dans TV-⁠Store. TV-⁠Store fonctionne sur les téléviseurs de 2017 et plus récents.

Sans TV-⁠Store

Aussi pour les téléviseurs d’avant 2017. Après l’étape 1, téléchargez le paquet et installez-le sur le téléviseur avec Apps2Samsung ; chaque mise à jour se fait de la même façon.

Code ouvert, sans compte

Toute l’application est sur GitHub : un cœur en Rust avec le moteur torrent, et une seule interface pour toutes les plateformes. Son code peut être lu, modifié et partagé pour tout usage non commercial selon la PolyForm Noncommercial License 1.0.0 ; l’usage commercial n’est pas autorisé.

  • Pas de compte reel, pas de connexion.
  • Aucun code d’analyse ni de suivi.
  • Les paramètres et la progression restent sur votre appareil.

À qui reel se connecte

  • Votre source de recherche, à l’adresse que vous avez saisie.
  • TMDB, AniList et Jikan, pour les titres, affiches et descriptions.
  • Une liste publique d’identifiants d’anime sur GitHub, pour faire correspondre les anime d’un catalogue à l’autre.
  • Les autres personnes qui partagent le film. Comme avec toute app torrent, elles voient votre adresse IP.
