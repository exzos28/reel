安装

下载 Mac 版搭载 Apple 芯片的 Mac
  1. 安装 AltStore 或 SideStore在 iPhone 或 iPad 上装好 AltStore 或 SideStore；AltStore 还需要电脑上的 AltServer。使用免费 Apple ID 时，应用每 7 天需要重新签名，这两款应用都会自动完成。
  2. 添加 reel 的源在 iPhone 或 iPad 上点按你所用应用的按钮，或将下面的地址添加为源。
    添加到 AltStore添加到 SideStore
    https://github.com/exzos28/reel/releases/latest/download/altstore.json
  3. 安装 reel在源中打开 reel 并安装。更新也会从这个源推送。
下载 Windows 版x64，解压后运行 reel.exe
下载 Linux 版ARM64，GTK 4.14 或更新
下载 APK手机、平板、电视
  1. 打开开发者模式在电视上打开“应用”，用遥控器按 1 2 3 4 5。打开开发者模式，并输入你电脑的 IP 地址。
  2. 打开 Apps2Samsung在电脑上安装 Apps2Samsung，打开后选择你的电视。
  3. 安装 reel下载安装包，用 Apps2Samsung 安装到电视上。下载 Samsung TV 版
