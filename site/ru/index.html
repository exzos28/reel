Установка

Скачать для MacMac с чипом Apple
  1. Установите AltStore Classic или SideStoreПоставьте AltStore Classic или SideStore на iPhone или iPad; для AltStore нужен ещё AltServer на компьютере. С бесплатным Apple ID приложения переподписываются каждые 7 дней, и оба приложения делают это сами. AltStore PAL не подойдёт: там только приложения, одобренные Apple.
  2. Добавьте источник reelНа iPhone или iPad нажмите кнопку своего приложения или добавьте адрес ниже как источник.
    Добавить в AltStore ClassicДобавить в SideStore
    https://github.com/exzos28/reel/releases/latest/download/altstore.json
  3. Установите reelОткройте reel в источнике и установите. Обновления тоже приходят оттуда.

Открытый код, без аккаунтов

Всё приложение — на GitHub: ядро на Rust с торрент-движком и один интерфейс для всех платформ. Код можно читать, менять и распространять для любых некоммерческих целей по лицензии PolyForm Noncommercial License 1.0.0; коммерческое использование запрещено.

  • Без аккаунта reel и без входа.
  • Без аналитики и кода слежения.
  • Настройки и прогресс просмотра хранятся на вашем устройстве.

С кем связывается reel

  • Ваш источник поиска — по адресу, который вы указали.
  • TMDB, AniList и Jikan — для названий, постеров и описаний.
  • Публичный список ID аниме на GitHub — чтобы сопоставлять аниме между каталогами.
  • Другие люди, которые раздают фильм. Как и в любом торрент-приложении, они видят ваш IP-адрес.
