# The core's modules

Generated by `app/tests/modules_map.rs` from the `#[module]`s in `app/src`: do not edit.
After changing a module, regenerate from `app/`:

```sh
UPDATE_MODULES_MAP=1 cargo test -p reel-app --test modules_map
```

Every NSH module the Rust core gives the UI (`app/native`, through `app/ui/native.ts`), by
name, with its methods by the names the TSX side calls (the Rust name in brackets when it
differs). Arguments and results are the Rust types. Most results are JSON strings: the
"JSON" line lists the shapes their doc comments spell out (the code builds them as
`serde_json::Value`s in `app/src`, so no Rust type names them). `async`
methods return a Promise in TS.

"Called from" lists the files (`app/App.tsx` and `app/ui`, without tests and the wiring in
`ui/native.ts` and `ui/native-http.ts`) that name `Module.method` outside a comment; a call
through another name would not show. "Nothing in the UI" can still be a host's call (the
TV's core sets `Sources.setProfile`) or one kept for later. On a TV the same modules are
served over HTTP by `platforms/tizen/core/src/table.rs`, which checks the names.

## Catalog

The catalog the UI shows: TMDB and AniList titles through `Meta`, releases from the user's search source, watch progress. Results are JSON strings; poll `revision()` and read again when it changes.

Native hosts only: not in the wasm32 web build (a TV reaches it over HTTP).

- `browse(page: String) -> String`: `"movies"`, `"shows"` or `"anime"`: `{"trending":[summary…],"all":[summary…], "filters":[group…],"allState"}` (see `catalog::browse`).
  JSON: `{"trending":[summary…],"all":[summary…], "filters":[group…],"allState"}`
  Called from: `ui/catalog.ts`.
- `browseMore(page: String) -> bool` (`browse_more`): The next page of a browse page's grid (`"movies"`, `"shows"`, `"anime"`): whether one is on its way now (`browse`'s `moreState` says when it is in).
  Called from: `ui/catalog.ts`.
- `async changed(after: f64) -> f64`: The revision once it is past `after`, or the same after a while: what the UI waits on to read again the moment something changed.
  Called from: `ui/catalog.ts`.
- `chooseFilter(page: String, group: String, id: String) -> bool` (`choose_filter`): One choice in a browse page's filter panel (see `catalog::choose_filter`): `group` "genres" | "years" | "countries" | "sort", `id` an option's id, empty to clear the group. Whether the filter changed.
  Called from: `ui/catalog.ts`.
- `chooseRelease(id: String, index: u32) -> bool` (`choose_release`): Makes release `index` the one Play uses for `id`.
  Called from: `ui/catalog.ts`.
- `episode(show: String, season: u32, number: u32) -> String`: Episode `number` of `season` of `show`, or null while it is not known.
  Called from: `ui/catalog.ts`.
- `episodeReleases(key: String) -> String` (`episode_releases`): The releases of one episode (an episode key), to pick one when it is not in its season's: `{"releases","releasesState","seasonRelease"}`.
  JSON: `{"releases","releasesState","seasonRelease"}`
  Called from: `ui/catalog.ts`.
- `episodes(show: String, season: u32) -> String`: The episodes of `season` of `show`.
  Called from: `ui/catalog.ts`.
- `forgetSearches()` (`forget_searches`): Forgets all the recent searches (the history's Clear).
  Called from: `ui/catalog.ts`.
- `home() -> String`: The home shelves: `[{"id","items":[summary…]}]` (see `catalog::summary`).
  JSON: `[{"id","items":[summary…]}]`
  Called from: `ui/catalog.ts`.
- `rememberSearch(query: String)` (`remember_search`): Keeps `query` among the recent searches (submitted, or a title opened from it).
  Called from: `ui/catalog.ts`.
- `revision() -> f64`: Goes up when anything the catalog shows changed (an answer landed, a search finished, progress was saved): read again.
  Called from: `ui/catalog.ts`.
- `saveProgress(id: String, position: f64, duration: f64) -> bool` (`save_progress`): The player's report: `position` of `duration` seconds into `id`. Whether it counts as watched now (90%).
  Called from: `ui/playback.ts`.
- `search(query: String) -> String`: The search screen for `query` (see `catalog::search::search`): `{"query","state","tmdb","recent","sections":[{"id","items":[summary…]}]}`. Asks in the background once the query rests; read again on `revision()`.
  JSON: `{"query","state","tmdb","recent","sections":[{"id","items":[summary…]}]}`
  Called from: `ui/catalog.ts`.
- `startAt(id: String) -> f64` (`start_at`): Where the player should start `id` (what plays), seconds: where the viewer stopped, 0 when new or watched.
  Called from: `ui/playback.ts`.
- `title(id: String) -> String`: A film or show screen (a notice title while it is not known yet).
  Called from: `ui/catalog.ts`.
- `toggleList(id: String) -> bool` (`toggle_list`): Adds `id` to the user's list or takes it off: whether it is on it now.
  Called from: `ui/catalog.ts`.
- `tracks(id: String) -> String`: The audio, subtitle and release options of what plays.
  Called from: `ui/Player.tsx`.
- `upNext(id: String, position: f64, duration: f64) -> String` (`up_next`): The episode to offer next at `position` of `duration` seconds of `id`, or null.
  Called from: `ui/Player.tsx`.

## Engine

The built-in torrent server (librqbit). Results are JSON strings.

Native hosts only: not in the wasm32 web build (a TV reaches it over HTTP).

- `checkSpace() -> String` (`check_space`): Whether there is room to start playing, as JSON `{"ok":bool,"free":bytes|null,"needed":bytes,"buffer":MiB}`.
  JSON: `{"ok":bool,"free":bytes|null,"needed":bytes,"buffer":MiB}`
  Called from: `ui/screens/settings/SettingsScreen.tsx`.
- `chooseTrack(job: u32, id: String, embedded: String, choice: String) -> String` (`choose_track`): The viewer picked `choice` (a key of `tracks`); subtitles are remembered for the title. The columns after it (as `tracks`).
  Called from: `ui/tracks.ts`.
- `close(job: u32)`: Stops the job and deletes what it downloaded (the cache is per film).
  Called from: `ui/playback.ts`.
- `cues(job: u32, id: u32, from: f64, to: f64) -> String`: The cues of subtitle file `id` on screen at some moment of `from..=to` seconds; the overlay asks with `from == to` at its position (see `Playback::cues`): `{"state","cues":[{"start","end","text"}]}`.
  JSON: `{"state","cues":[{"start","end","text"}]}`
  Called from: `ui/tracks.ts`.
- `firstFrame(job: u32)` (`first_frame`): The player shows the first frame of the job's film (for the timing log, `$TMPDIR/reel-timings.log`).
  Called from: `ui/playback.ts`.
- `open(id: String) -> u32`: Starts playing `id` from the catalog (a title, or an episode `<title>:s<season>e<episode>`) with the release it picks from the user's search source: a job id for `status`, 0 when the engine could not start (see the log).
  Called from: `ui/playback.ts`.
- `openRelease(source: String, season: u32, episode: u32) -> u32` (`open_release`): Starts playing a release a search found: `source` is its magnet or .torrent URL; `season`/`episode` (0 for a film) pick the episode's file in a pack. A job id for `status`, 0 when the engine could not start.
  Called from: nothing in the UI.
- `async seek(job: u32, seconds: f64) -> String`: Gets the place at `seconds` ready before the view seeks there (no player waits in pieces still to come: a TV's AVPlay holds the page meanwhile). `{"state":…}`: `ready` once it is in (at once when it was), `replaced` when a newer seek or `close` came first, `unknown` when the film has no index to tell (seek as it is).
  JSON: `{"state":…}`
  Called from: `ui/VideoSurface.tsx`.
- `status(job: u32) -> String`: What the player shows for the job, JSON with a `phase` (see `Playback::status`).
  Called from: `ui/playback.ts`.
- `subtitles(job: u32) -> String`: The subtitle files of what the job plays (fetching them starts with the first ready answer): `{"state":"pending"|"ready","files":[{"id", "language","label","format"}]}` (see `Playback::subtitles`).
  JSON: `{"state":"pending"|"ready","files":[{"id", "language","label","format"}]}`
  Called from: nothing in the UI.
- `timeline(job: u32, position: f64, duration: f64, cached: f64, read_byte: f64, read_time: f64) -> String`: What the scrubber draws at `position` of `duration` seconds: `{"ranges":[[from,to],…],"ahead":seconds}` (see `Playback::timeline`). `cached`: seconds the video view holds in memory ahead of `position` (mpv's cache), shown as ready with what is on disk. `read_byte`/`read_time`: the byte of the file the view has read to and the moment of the film it holds there (0: unknown), which places what is on disk in time.
  JSON: `{"ranges":[[from,to],…],"ahead":seconds}`
  Called from: `ui/playback.ts`.
- `tracks(job: u32, id: String, embedded: String) -> String`: The Audio and Subtitles columns of the tracks panel for the job playing `id`, with what the video view should apply. `embedded` is the view's `tracks` event as JSON, empty where the view reports none (see `tracks::menu`).
  Called from: `ui/tracks.ts`.

## Hosted

Settings from a phone: the page this device serves on the local network (docs/hosted-settings.md), as the TV's own UI shows it.

Native hosts only: not in the wasm32 web build (a TV reaches it over HTTP).

- `address() -> String`: Where to open the page: `{"url":"http://192.168.1.20:47392/settings"}`, or `{"url":null}` where this device does not serve it or has no network address.
  JSON: `{"url":"http://192.168.1.20:47392/settings"}`, `{"url":null}`
  Called from: `ui/hosted.ts`.
- `answerOffer(accept: bool)` (`answer_offer`): The viewer's answer to the offered source; a yes saves and checks it.
  Called from: `ui/hosted.ts`.
- `cancelPairing()` (`cancel_pairing`): The viewer dismissed the code (Back).
  Called from: `ui/hosted.ts`.
- `link() -> String`: The QR code of the settings page: `{"url","qr"}` (`qr` an SVG data URL), or nulls where the page is not served.
  JSON: `{"url","qr"}`
  Called from: `ui/hosted.ts`.
- `linkSource(link: String) -> String` (`link_source`): The source in a link that opened the app (`reel://s?t=<key>&u=<address>`, from a partner's bot): `{"url","key"}`, or `{"url":null}` for any other link. Nothing is saved.
  JSON: `{"url","key"}`, `{"url":null}`
  Called from: `App.tsx`.
- `offered() -> String`: The source a phone offers (from a partner's link), waiting for a yes on the screen: `{"host":"jackett.example.com"}` or `{"host":null}`.
  JSON: `{"host":"jackett.example.com"}`, `{"host":null}`
  Called from: `ui/hosted.ts`.
- `pairing() -> String`: The code to show while a browser pairs: `{"code":"482913","expiresIn":115}`, or `{"code":null}`.
  JSON: `{"code":"482913","expiresIn":115}`, `{"code":null}`
  Called from: `ui/hosted.ts`.
- `partner() -> String`: The partner's bot and the links to it: `{"bot","tv":{"url","qr"}|null,"app":{"url","qr"}}`, or `{"bot":null}` in a build without one.
  JSON: `{"bot","tv":{"url","qr"}|null,"app":{"url","qr"}}`, `{"bot":null}`
  Called from: `ui/hosted.ts`.

## Library

Saving films and episodes to watch offline (design/offline-downloads.md). Results are JSON strings; states and messages are keys the UI words (`saved.*`).

Native hosts only: not in the wasm32 web build (a TV reaches it over HTTP).

- `item(key: String) -> String`: One key's state for its button: `{"state","progress","id","message"}` (see `library::item`).
  JSON: `{"state","progress","id","message"}`
  Called from: `ui/library.ts`.
- `list() -> String`: The Saved screen: `{"saving":[…],"ready":[…],"failed":[…],"space":{"saved","free", "folder"}}`, each item `{"id","key","title","label","image","season","number","state", "size","have","progress","speed","peers","message","folder"}`.
  JSON: `{"saving":[…],"ready":[…],"failed":[…],"space":{"saved","free", "folder"}}`, `{"id","key","title","label","image","season","number","state", "size","have","progress","speed","peers","message","folder"}`
  Called from: `ui/library.ts`.
- `openFolder() -> bool` (`open_folder`): Opens the folder saved films go into in the system's file manager (desktops); false where there is none or it did not open.
  Called from: `ui/library.ts`.
- `pause(id: u32)`: Pauses saving the item (its whole torrent: episodes of one pack pause together).
  Called from: `ui/library.ts`.
- `plan(show: String, season: u32) -> String`: The Save drawer for a season: `{"episodes":[{"key","number","title","size","state", "progress","locked"}],"saved","total","size"}`.
  JSON: `{"episodes":[{"key","number","title","size","state", "progress","locked"}],"saved","total","size"}`
  Called from: `ui/library.ts`.
- `remove(id: u32)`: Stops saving the item and deletes its files.
  Called from: `ui/library.ts`.
- `resume(id: u32)`: Goes on saving a paused item.
  Called from: `ui/library.ts`.
- `revision() -> f64`: Goes up when anything the Saved screen and the Save buttons show changed.
  Called from: nothing in the UI.
- `save(keys: String) -> bool`: Saves the catalog keys in `keys` (a JSON array: a film, or episodes) once their release is known; what is saved already stays. False when this device saves nothing.
  Called from: `ui/library.ts`.
- `setFolder(folder: String) -> String` (`set_folder`): Saves new items into `folder` from now on: "" when done, else why not.
  Called from: nothing in the UI.
- `supported() -> bool`: Whether this device saves films (false on TVs and without the engine): no Save control shows when it does not.
  Called from: `ui/library.ts`.
- `title(id: String, show: bool) -> String`: The Save button of a title (`show`: a series): `{"state","saved","saving","progress"}`.
  JSON: `{"state","saved","saving","progress"}`
  Called from: `ui/library.ts`.

## Meta

Movie, series and anime metadata: TMDB, AniList, Jikan (MAL score), tied by the Fribb anime ID lists, cached in SQLite. Results are JSON strings.

The data calls (`trending`, `title`, `season`, `search`) return Promises that never block the UI: they answer from the cache at once when they can (a stale answer, `"stale": true`, is refreshed in the background, and `revision()` goes up when the refresh lands, so poll it and ask again); only a cache miss waits for the network (15 s timeout, rate limits per source). Each resolves to `{"data","stale","fetchedAt","error","warnings","revision"}`. `language` is a BCP 47 tag ("en", "pl-PL"): text comes from the source in that language when it has it.

Native hosts only: not in the wasm32 web build (a TV reaches it over HTTP).

- `attribution() -> String`: What the About/Credits screen must show: `[{"provider","name","url", "notice","logoRequired","license"}]` (TMDB's notice is required, with its logo).
  JSON: `[{"provider","name","url", "notice","logoRequired","license"}]`
  Called from: `ui/screens/about/AboutScreen.tsx`.
- `init(data_dir: String) -> String`: Opens the cache in `data_dir` (`process.dataDir`; empty: in memory) and starts the anime lists download when due. The status (see `status`).
  Called from: nothing in the UI.
- `revision() -> f64`: Goes up whenever a background refresh stored newer data: ask again for what is on screen when it changes.
  Called from: nothing in the UI.
- `async search(query: String, language: String) -> String`: Search: `data` is `{"sections":[{"source":"tmdb"|"anilist","items":[TitleCard]}]}`; an anime TMDB found is not repeated under AniList.
  JSON: `{"sections":[{"source":"tmdb"|"anilist","items":[TitleCard]}]}`
  Called from: nothing in the UI.
- `async season(id: String, season: u32, language: String) -> String`: TMDB season `season` (0 = specials) of a series: `data` is a Season with its episodes.
  Called from: nothing in the UI.
- `setTmdbKey(key: String) -> String` (`set_tmdb_key`): Uses the user's own TMDB key (v4 read access token or v3 key) instead of the project one; empty clears it. Kept in memory. The status.
  Called from: nothing in the UI.
- `status() -> String`: Which sources work: `{"tmdb":{"configured","requiresKey","capabilities", "key":"user"|"build"|null},"anilist","jikan":{"configured","requiresKey","capabilities"}, "animeLists":{"entries","fetchedAt","updating"},"cache":{"persistent"},"revision"}`.
  JSON: `{"tmdb":{"configured","requiresKey","capabilities", "key":"user"|"build"|null},"anilist","jikan":{"configured","requiresKey","capabilities"}, "animeLists":{"entries","fetchedAt","updating"},"cache":{"persistent"},"revision"}`
  Called from: nothing in the UI.
- `async title(id: String, language: String) -> String`: A title by our ID ("tmdb:movie:603", "tmdb:tv:1399", "anilist:21"): `data` is a Title. An AniList ID the anime lists tie to one TMDB title answers with that title (its `id` is the TMDB one).
  Called from: nothing in the UI.
- `async trending(kind: String, language: String) -> String`: A home shelf: `kind` is "movie" | "tv" (TMDB trending this week), "movie-popular" | "tv-popular" (TMDB discover), "anime" (AniList trending) | "anime-popular" (AniList, this season). `data`: `{"items":[TitleCard]}`.
  JSON: `{"items":[TitleCard]}`
  Called from: nothing in the UI.

## Settings

The user's settings, kept on the device.

Native hosts only: not in the wasm32 web build (a TV reaches it over HTTP).

- `async changed(after: f64) -> f64`: The revision once it is past `after`, or the same after a while: what the UI waits on.
  Called from: `ui/hosted.ts`.
- `current() -> String`: The settings as `load` answers them, from memory (after a change made elsewhere, e.g. on the hosted page from a phone).
  Called from: `ui/hosted.ts`.
- `device() -> String`: The kind of device, when the host knows better than the system ("tv" on a Samsung TV, whose web view NSH takes for a desktop browser; a development host's stand-in, `compat::set_device`); empty otherwise.
  Called from: `ui/platform/index.ts`.
- `finishSetup()` (`finish_setup`): The first-run setup is done (it does not show again).
  Called from: `ui/preferences.ts`.
- `load(data_dir: String) -> String`: Loads the settings from `data_dir` (the app's data directory, empty when the host has none) and configures the engine from them; JSON `{"language","bufferMB","bufferChoices":[{"mb","default"}]}`.
  JSON: `{"language","bufferMB","bufferChoices":[{"mb","default"}]}`
  Called from: `ui/preferences.ts`.
- `revision() -> f64`: Goes up when the settings change (here or on the hosted page) and when the hosted page's pairing code appears or goes: read `current` and `Hosted.pairing` again.
  Called from: `ui/hosted.ts`.
- `setBufferMb(mb: u32) -> u32` (`set_buffer_mb`): Saves the playback buffer size (one of the choices); the size in effect.
  Called from: `ui/preferences.ts`.
- `setContentLanguage(tag: String) -> String` (`set_content_language`): Saves the content language (titles, descriptions, episode names; one of `contentLanguages` from `load`) and drops what was asked in the old one; the language in effect.
  Called from: `ui/preferences.ts`.
- `setLanguage(tag: String)` (`set_language`): Saves the UI language (a BCP 47 tag).
  Called from: nothing in the UI.
- `setLoader(loader: String) -> String` (`set_loader`): Saves the loading animation ("logo" or "dinosaur"; another value is refused); the one in effect.
  Called from: `ui/preferences.ts`.
- `setNavPosition(position: String) -> String` (`set_nav_position`): Saves where the top nav sits on a TV and a desktop ("left", "center" or "right"; another value is refused); the position in effect.
  Called from: `ui/preferences.ts`.
- `setSource(url: String, key: String) -> String` (`set_source`): Saves the search source (a Torznab endpoint and its key; empty URL removes it). JSON `{"ok":true,"source":{"url","hasKey"}}` or `{"ok":false,"message"}` for an address that is not one.
  JSON: `{"ok":true,"source":{"url","hasKey"}}`, `{"ok":false,"message"}`
  Called from: `ui/preferences.ts`.
- `setStreamDetails(on: bool) -> bool` (`set_stream_details`): Saves whether the player shows the stream's speed, people and what is ready ahead (off by default); the value in effect.
  Called from: `ui/preferences.ts`.

## Sources

Finding releases on the user's own source (Torznab). Searches run in the background: start one, then poll `result`.

Native hosts only: not in the wasm32 web build (a TV reaches it over HTTP).

- `check() -> u32`: Checks the saved source (`t=caps`); a job id for `result`, 0 when none is set.
  Called from: `ui/preferences.ts`.
- `result(id: u32) -> String`: `{"state":"pending"}`, `{"state":"done","releases":[…]}` (ranked: each `{"id","title","source","infohash","size","seeders","peers","indexer", "info":{resolution,hdr,dolby_vision,codec,source,season,episodes,season_pack}, "seasonPack"}`), `{"state":"done","caps":{…}}` for a check, or `{"state":"failed","message"}`.
  JSON: `{"state":"pending"}`, `{"state":"done","releases":[…]}`, `{"id","title","source","infohash","size","seeders","peers","indexer", "info":{resolution,hdr,dolby_vision,codec,source,season,episodes,season_pack}, "seasonPack"}`, `{"state":"done","caps":{…}}`, `{"state":"failed","message"}`
  Called from: `ui/preferences.ts`.
- `search(request: String) -> u32`: Searches for a film or an episode. `request` is JSON `{"imdb","title","year","season","episode"}` (imdb, year, season and episode optional). A search id for `result`; 0 when no source is set.
  Called from: nothing in the UI.
- `setPictureCap(lines: u32)` (`set_picture_cap`): The tallest picture Play picks by itself, in lines (1080 on a phone or a tablet: 4K costs it time and space for nothing it can show); 0: any. The viewer can still choose any release.
  Called from: `App.tsx`.
- `setProfile(name: String) -> bool` (`set_profile`): Sets the player profile of this device (what it can play): "mpv", "apple_avplayer", "android_mediaplayer", "tizen". Releases it cannot play are hidden from searches. False for an unknown name.
  Called from: nothing in the UI.

## VideoEngine

Which video view plays on this device.

Native hosts only: not in the wasm32 web build (a TV reaches it over HTTP).

- `fullscreen(on: bool)`: The player's full screen (Android: the system bars hide while it plays; elsewhere nothing: the desktops have their own full screen, a TV is always full).
  Called from: `ui/platform/window.ts`.
- `kind() -> String`: `"mpv"` where reel's mpv view (`reel/mpv`) can play (macOS with libmpv found: MKV, every codec, track selection), else `"native"` (NSH's `<Video>`, the platform's player). Choosing mpv also sets the search profile to it, so releases only mpv plays are offered. On a Samsung TV (the `tizen` profile its host sets) `"avplay"`: the TV shell's AVPlay draws under the web UI.
  Called from: `ui/VideoSurface.tsx`.
- `views() -> bool`: Whether reel's own native views are registered on this device (Android: the Java ones `build/android-views.sh` adds to the APK; registered on the first call).
  Called from: nothing in the UI.
